  Удобное десктопное приложение для отслеживания и ведения списков аниме.
  
Проект написан с помощью ИИ

✨ Возможности оформления карточки
* **Всё в одном месте:** больше не придётся искать сайт с аниме, вспоминать любимую озвучку или серию, на которой вы когда-то остановились — все эти данные теперь хранятся прямо в карточке тайтла.
* **Гибкая настройка обложек:** загружайте свои изображения из локальной папки или находите нужные арты через встроенный браузер прямо в приложении — достаточно просто ввести название.
* **Быстрое редактирование:** вы всегда можете обновить информацию — введите название нужного аниме, чтобы быстро найти его в базе, и скорректируйте любые детали.
 <img width="466" height="350" alt="image" src="https://github.com/user-attachments/assets/f6173817-192e-4989-b585-e3ece4490d7d" />

✨ Простая сортировка списка
* **Управление статусами:** легко отмечайте уже просмотренные тайтлы и добавляйте самое лучшее в «Избранное» для быстрого доступа.
<img width="448" height="412" alt="image" src="https://github.com/user-attachments/assets/9dbd13e5-3508-4ef3-b7fd-14fac5dbb402" />

✨ Слишком много тайтлов?
* **Мгновенный поиск:** встроенный фильтр поможет в один клик найти нужное аниме, даже если ваша библиотека разрослась до сотен позиций.

✨ Кастомизация интерфейса
* **Персонализация меню:** настраивайте внешний вид приложения под себя.
  * Доступны классические светлая и тёмная темы.
  * Возможность выбора собственного фона и настройки прозрачности списков.
